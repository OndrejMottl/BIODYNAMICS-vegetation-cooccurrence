# Scope and decision status

This is a diagnostic investigation of Stem specific density, Leaf mass per area and Leaf nitrogen content per unit mass after the ten already approved source rules have been applied.
It does not approve or apply any additional correction.

The comparison uses taxa observed in more than one source.
For each source-domain combination, its taxon medians are compared with the median from all other sources for the same taxa.
The nearest power-of-ten ratio describes a comparative scale cluster only; it is not a proposed conversion factor.
Biological differences among sources can create the same pattern.

# Intended unit contract

The intended units are anchored to the [official TRY Global Spectrum release](https://www.try-db.org/TryWeb/Data.php#81), whose six fields match this project's six trait domains.


|trait_domain_name                   |intended_unit |provenance_status           |
|:-----------------------------------|:-------------|:---------------------------|
|Leaf mass per area                  |g/m2          |TRY Global Spectrum release |
|Leaf nitrogen content per unit mass |mg/g          |TRY Global Spectrum release |
|Stem specific density               |mg/mm3        |TRY Global Spectrum release |

VegVault 1.0.0 did not retain a usable unit field for these records.
Its archived TRY preparation selected `OrigValueStr` rather than TRY's standardized numeric value, and it reciprocated original SLA values without first normalizing the SLA unit.
Therefore source metadata, not cross-source magnitude alone, must establish any conversion.

# Leaf mass per area

The intended LMA unit is g/m2.
The source clusters cannot be translated directly into correction factors because some values are original LMA while others were created by reciprocating SLA recorded in unknown original units.
For example, a value near 100 can be valid LMA in g/m2, whereas a value near 0.05 can be a reciprocal expressed as kg/m2 and would require a different conversion.
A log transformation cannot repair this provenance problem.
