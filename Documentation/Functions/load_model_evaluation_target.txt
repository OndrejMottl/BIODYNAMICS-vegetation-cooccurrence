Load a Model Evaluation Target

Description:

     Loads one explicit fitted or cross-validated model-evaluation
     target from a targets store. If the target cannot be read, `NULL`
     is returned.

Usage:

     load_model_evaluation_target(
       store_path,
       resolution_id,
       evaluation_type = base::c("fitted", "cross_validated"),
       read_target_fn = targets::tar_read_raw
     )

Arguments:

store_path: A single character string with the targets store path.

resolution_id: A single non-empty character string identifying the
          model resolution.

evaluation_type: Evaluation target type. One of `"fitted"` or
          `"cross_validated"`.

read_target_fn: Function used to read the target. Defaults to
          [targets::tar_read_raw()].

Value:

     The model evaluation object, or `NULL` if it cannot be read.

Examples:

     ## Not run:

     load_model_evaluation_target(
       store_path = "Data/targets/modern_spatial_continental/europe",
       resolution_id = "genus",
       evaluation_type = "cross_validated"
     )
     ## End(Not run)
