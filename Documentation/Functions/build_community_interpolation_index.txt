Build Community Interpolation Index

Description:

     Builds small per-dataset row-range metadata for paleo
     interpolation.

Usage:

     build_community_interpolation_index(
       data_community = NULL,
       data_age_uncertainty = NULL
     )

Arguments:

data_community: A data frame containing a `dataset_name` column. Rows
          for each dataset must be contiguous.

data_age_uncertainty: A data frame containing a `dataset_name` column.
          Rows for each dataset must be contiguous. Datasets without
          uncertainty rows are supported.

Details:

     Dynamic `targets` branches receive constant-size row ranges
     instead of nested data frames. This avoids scanning the complete
     shared inputs and allocating a full-table logical mask in every
     worker branch.

Value:

     A list of branch metadata objects. Each object contains
     `dataset_name`, `flag_empty`, and inclusive row ranges for both
     shared input tables.

See Also:

     [interpolate_community_dataset_from_shared_inputs()]

Examples:

     data_community <-
       tibble::tibble(
         dataset_name = base::c("core_b", "core_a")
       )
     data_age_uncertainty <-
       tibble::tibble(
         dataset_name = "core_a"
       )

     build_community_interpolation_index(
       data_community = data_community,
       data_age_uncertainty = data_age_uncertainty
     )
