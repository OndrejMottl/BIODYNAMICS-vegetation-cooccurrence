Build One sjSDM Candidate-Fold Result

Description:

     Constructs one typed tuning row and its compact prediction-cache
     record for a completed or failed candidate lifecycle.

Usage:

     build_sjsdm_candidate_fold_result(
       data_candidate = NULL,
       list_fold_context = NULL,
       fit_seed = NA_integer_,
       score_seed = NA_integer_,
       fit_status = NULL,
       error_message = NA_character_,
       data_metrics = NULL,
       data_predicted = NULL,
       fit_seconds = NA_real_,
       prediction_seconds = NA_real_,
       scoring_seconds = NA_real_
     )

Arguments:

data_candidate: One-row candidate table with the candidate identifier
          and six parameters.

list_fold_context: Fold context containing identifiers, sizes, and the
          CV strategy.

fit_seed, score_seed: Derived candidate seeds, or typed missing
          integers before candidate work.

fit_status: One of `preparation_error`, `fit_error`,
          `prediction_error`, `scoring_error`, or `ok`.

error_message: Character failure message, or a missing character value
          for success.

data_metrics: Optional named list of the five candidate scoring
          metrics.

data_predicted: Optional held-out probability matrix. Fitted model
          objects are never stored.

fit_seconds, prediction_seconds, scoring_seconds: Candidate lifecycle
          timings in seconds.

Value:

     Named list containing one-row `data_tuning` and `list_prediction`.
