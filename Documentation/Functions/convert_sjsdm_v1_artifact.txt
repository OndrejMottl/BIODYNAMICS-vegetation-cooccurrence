Convert a Frozen v1 sjSDM Artifact Bundle

Description:

     Converts one strictly identified v1 target bundle into the common
     v2 envelope without modifying its source store.

Usage:

     convert_sjsdm_v1_artifact(
       artifact_type = NULL,
       payload = NULL,
       v1_schema_hash = NULL,
       pipeline_id = NULL,
       configuration_profile = NULL,
       migration_function = NULL,
       created_at = base::Sys.time()
     )

Arguments:

artifact_type: Registered v2 artifact type.

 payload: Named v2 payload assembled from validated v1 targets.

v1_schema_hash: Frozen v1 schema-fixture hash.

pipeline_id: Source pipeline identifier.

configuration_profile: Source configuration profile.

migration_function: Explicit converter name.

created_at: Conversion time.

Value:

     Validated migrated v2 artifact envelope.
