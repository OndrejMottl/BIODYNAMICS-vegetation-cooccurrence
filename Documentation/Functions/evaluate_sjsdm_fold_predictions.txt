Evaluate sjSDM Predictions Within Cross-Validation Folds

Description:

     Calculates model and prevalence-null prediction metrics separately
     within each repeat, fold, and taxon.

Usage:

     evaluate_sjsdm_fold_predictions(data_predictions = NULL, epsilon = 1e-06)

Arguments:

data_predictions: Long selected-candidate OOF prediction table returned
          in the data-prediction element of
          [run_sjsdm_selected_candidate_folds()].

 epsilon: Probability clipping tolerance passed to
          [evaluate_binary_log_loss()]. Defaults to 1e-6.

Details:

     Unlike [evaluate_sjsdm_cross_validated_predictions()], this
     function never pools probabilities from separately fitted fold
     models. Model and null predictions are evaluated independently, so
     an unavailable model prediction does not suppress a valid
     prevalence-null diagnostic.

Value:

     Tibble with one row per repeat, fold, taxon, prediction source,
     and metric. Prediction sources are model and prevalence_null;
     metrics are Tjur R2, AUC, binary log loss, Brier score,
     calibration intercept, and calibration slope.

Examples:

     ## Not run:

     evaluate_sjsdm_fold_predictions(
       data_predictions = data_predictions
     )
     ## End(Not run)
