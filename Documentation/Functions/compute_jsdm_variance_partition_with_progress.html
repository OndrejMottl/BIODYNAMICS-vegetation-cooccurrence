compute_jsdm_variance_partition_with_progressR Documentation

Compute sjSDM Decomposition with Conditional Likelihood Progress

Description

Runs the installed sjSDM 1.0.7 ANOVA method unchanged in a private execution environment with an instrumented conditional-likelihood iteration adapter. No package namespace or installed file is modified.

Usage

compute_jsdm_variance_partition_with_progress(
  mod,
  n_samples = 5000L,
  verbose = FALSE,
  anova_function = NULL
)

Arguments

mod

Fitted sjSDM object.

n_samples

Positive Monte Carlo sample count; passed unchanged.

verbose

Logical; print per-taxon start and completion timestamps.

anova_function

Injectable ANOVA method; defaults to installed sjSDM.

Details

This sensitivity-only adapter fails closed on unsupported dependency versions or changed ANOVA and conditional-likelihood bodies. It does not change prediction calls, RNG order, fitting settings, or batch size.

Value

The installed ANOVA method's result, with unchanged scientific rules.

Examples

## Not run:
compute_jsdm_variance_partition_with_progress(
  mod = mod_jsdm,
  n_samples = 1000L,
  verbose = TRUE
)

## End(Not run)
