Assess sjSDM Candidate Guardrails

Description:

     Compares a tuning candidate with its reference across tuning
     repeats and an independent fold-local refit.

Usage:

     evaluate_sjsdm_candidate_guardrails(
       data_tuning_summary = NULL,
       data_candidate_repeat_metrics = NULL,
       data_reference_repeat_metrics = NULL,
       candidate_id = NULL,
       reference_candidate_id = NULL,
       maximum_discrimination_decrease = 0.01,
       minimum_tjur_r2 = 0.1
     )

Arguments:

data_tuning_summary: Repeat-by-candidate tuning summary.

data_candidate_repeat_metrics: Candidate repeat metrics from
          [summarise_sjsdm_fold_metrics()].

data_reference_repeat_metrics: Reference repeat metrics with the same
          schema as the candidate metrics.

candidate_id: Candidate identifier to assess.

reference_candidate_id: Reference identifier used for comparison.

maximum_discrimination_decrease: Largest allowed repeat-level decrease
          in AUC or Tjur R2. Defaults to `0.01`.

minimum_tjur_r2: Minimum candidate mean fold-macro Tjur R2. Defaults to
          `0.1`.

Details:

     Acceptance requires lower tuning NLL in every repeat, tuning AUC
     within the discrimination tolerance, non-inferior
     independent-refit AUC, Tjur R2, log loss, and Brier score in every
     repeat, and the scientific Tjur R2 gate.

Value:

     A named list containing tuning-repeat comparisons,
     independent-refit comparisons, and a one-row guardrail summary.

Examples:

     ## Not run:

     evaluate_sjsdm_candidate_guardrails(
       data_tuning_summary = data_tuning,
       data_candidate_repeat_metrics = data_candidate_metrics,
       data_reference_repeat_metrics = data_reference_metrics,
       candidate_id = "candidate_002",
       reference_candidate_id = "candidate_001"
     )
     ## End(Not run)
