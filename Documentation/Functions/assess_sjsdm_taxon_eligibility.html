Assess sjSDM Taxon Eligibility

Description

Applies prespecified prevalence and fold-evaluability rules to fold-local sjSDM metrics.

Usage

assess_sjsdm_taxon_eligibility(
  data_fold_metrics = NULL,
  minimum_prevalence = 0.05,
  maximum_prevalence = 0.95,
  minimum_evaluable_fraction = 0.8
)

Arguments

data_fold_metrics

Fold-local metric table returned by [evaluate_sjsdm_fold_predictions()].

minimum_prevalence

Minimum observation-weighted prevalence. Defaults to '0.05'.

maximum_prevalence

Maximum observation-weighted prevalence. Defaults to '0.95'.

minimum_evaluable_fraction

Minimum fraction of folds with an evaluable model Tjur R2. Defaults to '0.8'.

Details

Eligibility is based only on model Tjur R2 rows. Prevalence is calculated from summed held-out presences and observations so unequal folds are weighted by their observation counts.

Value

One-row-per-taxon tibble with prevalence, fold coverage, mean evaluable Tjur R2, component checks, overall eligibility, and a deterministic status.

Examples
