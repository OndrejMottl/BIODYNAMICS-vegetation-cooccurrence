load_temporal_slice_agesR Documentation

Load the Modelled Temporal Slice Ages

Description

Returns the time slices that a paleo temporal profile models, from the profile's modelled-slice window and time step.

Usage

load_temporal_slice_ages(
  config_id = base::Sys.getenv("R_CONFIG_ACTIVE"),
  file = here::here("config.yml"),
  flag_modelled_only = TRUE
)

Arguments

config_id

Configuration profile identifier. Defaults to the active profile ('R_CONFIG_ACTIVE').

file

Path to the generated configuration file.

flag_modelled_only

Logical. If 'TRUE' (default), return only modelled slices. If 'FALSE', also return slices inside the window that the profile excludes, with a 'flag_modelled' column.

Details

The window is 'temporal_slices.age_window' and the step is 'data_processing.time_step'. The window is deliberately separate from 'vegvault_data.age_lim', which bounds data extraction and feeds the expensive age interpolation: narrowing the modelled window must not invalidate that preparation. Slices outside the window are not modelled.

'temporal_slices.excluded_ages' (optional) lists ages inside the window that are known to be infeasible, such as a slice with fewer samples than 'min_n_samples'. They are left out of the pipeline because an infeasible slice aborts the whole temporal build at its dynamic tuning branches ('cannot branch over empty target'), which would block every other slice.

Value

A tibble with columns 'age' (numeric, years BP) and 'age_name' ('timeslice_<age>'), one row per slice in increasing age, plus 'flag_modelled' when 'flag_modelled_only = FALSE'.

Examples

load_temporal_slice_ages(config_id = "project_paleo_temporal_europe")
