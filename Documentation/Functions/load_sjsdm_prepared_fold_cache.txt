Load the Prior Local Prepared-Fold Object

Description:

     Reads the prior local object without consulting target metadata
     during target execution. Missing, unreadable or non-list objects
     return NULL. Analytical cache eligibility remains owned by
     [prepare_sjsdm_tuning_folds()], which reconstructs current inputs
     first.

Usage:

     load_sjsdm_prepared_fold_cache(
       file_cache = targets::tar_path_target(store = targets::tar_path_store()),
       read_cache_function = qs2::qs_read
     )

Arguments:

file_cache: Local object path. The default uses the documented
          current-target path with the running store; outside target
          execution it resolves to NA.

read_cache_function: Injectable file reader accepting a named file
          argument. Defaults to the project's qs2 reader, compatible
          with its current local qs target objects.

Value:

     The prior list object or NULL. No target metadata are changed.

Examples:

     load_sjsdm_prepared_fold_cache(file_cache = "missing-fold-cache.qs")
