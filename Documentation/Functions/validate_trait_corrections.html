validate_trait_correctionsR Documentation

Validate Trait Correction Approval

Description

Checks that every trait-correction row has been reviewed by a human. Acts as a pipeline guard: if any row has a 'CHECKED' value that is not 'TRUE', the function calls 'cli::cli_abort()' so the pipeline stops until a human has signed off every row.

Usage

validate_trait_corrections(data_trait_corrections)

Arguments

data_trait_corrections

A data frame loaded by [load_trait_corrections()]. Must contain a logical 'CHECKED' column.

Details

The abort message reports exactly how many rows have not been validated and instructs the user to set 'CHECKED = TRUE' after reviewing.

Value

A tibble of validated corrections (all rows have 'CHECKED == TRUE') when every row is approved. Aborts via 'cli::cli_abort()' if any row is not yet validated.
