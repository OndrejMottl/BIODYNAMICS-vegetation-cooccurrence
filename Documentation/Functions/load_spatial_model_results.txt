Load Spatial Model Results

Description:

     Loads successful spatial model ANOVA and evaluation targets from
     indexed targets stores and returns one summary row per
     store-resolution-component combination.

Usage:

     load_spatial_model_results(
       store_index,
       resolution_ids,
       read_target_fn = targets::tar_read_raw,
       meta_fn = targets::tar_meta,
       require_non_empty = FALSE
     )

Arguments:

store_index: Data frame returned by
          [build_spatial_model_store_index()].

resolution_ids: Character vector of model resolution identifiers.

read_target_fn: Function used to load one target. Defaults to
          [targets::tar_read_raw()].

 meta_fn: Function used to load target metadata. Defaults to
          [targets::tar_meta()].

require_non_empty: Logical. If `TRUE`, error when no rows are loaded.

Value:

     A tibble with ANOVA component percentages, explicitly labelled
     fitted AUC, and cross-validated predictive Tjur R2, AUC, and log
     loss.
