Build Trait Analysis Release

Description:

     Freezes corrected VegVault trait records behind an explicit
     six-domain analysis contract and records the reviewed unit and
     evidence status of each domain.

Usage:

     build_trait_analysis_release(
       data_trait_records,
       data_trait_domain_units,
       vegvault_version,
       release_id,
       release_date
     )

Arguments:

data_trait_records: Corrected classified trait records with
          `trait_domain_name`, `trait_unit`, and a numeric
          `trait_value`.

data_trait_domain_units: The validated trait-domain unit table of the
          release, as returned by [validate_trait_domain_units()].

vegvault_version: Character scalar VegVault version of the release (the
          `vegvault_version` of the `config_vegvault_release` target).

release_id: Character scalar stable release identifier. It must start
          with `vegvault_` and the version with underscores, for
          example `vegvault_2_0_0_reviewed_2026_12_01`.

release_date: Character scalar release date in ISO format
          (`YYYY-MM-DD`).

Details:

     The release stops with an error when the unit table belongs to
     another VegVault release, when `release_id` names another release,
     when the records or the unit table do not hold exactly the six
     supported domains, or when a record's unit differs from the unit
     of its domain. The domain statuses come from the reviewed unit
     table, not from this function.

Value:

     A list containing the unchanged `data_trait_records` and a
     `data_trait_domain_status` tibble: the unit table with
     `release_id` and `release_date` in front, one row per domain.

See Also:

     [validate_trait_domain_units()], [load_trait_domain_units()]

Examples:

     ## Not run:

     build_trait_analysis_release(
       data_trait_records = data_traits_classified_corrected,
       data_trait_domain_units = data_trait_domain_units_validated,
       vegvault_version = "2.0.0",
       release_id = "vegvault_2_0_0_reviewed_2026_12_01",
       release_date = "2026-12-01"
     )
     ## End(Not run)
