Load Trait Domain Units

Description:

     Strictly loads the reviewed table that records one unit per trait
     domain for one VegVault release (`trait_domain_units.csv` in the
     release folder of the trait corrections).

Usage:

     load_trait_domain_units(path_trait_domain_units)

Arguments:

path_trait_domain_units: Character scalar path to a canonical
          trait-domain unit CSV.

Details:

     The header must hold the canonical columns in order. Empty cells
     are read as `NA`, and cell text is not trimmed, so that
     [validate_trait_domain_units()] can reject edge whitespace. The
     function stops when any cell cannot be parsed to its column type.

Value:

     A typed tibble with the columns `vegvault_version`,
     `vegvault_build_reference`, `trait_domain_name`, `trait_unit`,
     `evidence_status`, `included_in_primary` (logical), `rationale`,
     `evidence_reference`, `review_status`, `reviewer`, and
     `reviewed_at`.

See Also:

     [validate_trait_domain_units()],
     [resolve_trait_correction_directory()]
