Build Programmatic Trait Review Triage

Description:

     Proposes no action only after completed investigation, retains
     unresolved evidence for programmatic review, and groups
     reproducible correction hypotheses for cost-gated agent
     investigation.

Usage:

     build_trait_review_programmatic_triage(
       data_candidate_recommendations,
       data_approved_decisions,
       data_proposal_diagnostics,
       data_dataset_evidence,
       data_record_evidence,
       data_agent_adjudications,
       evidence_reference,
       min_source_pattern_candidates = 3L,
       source_factor_relative_tolerance = 0.25,
       agent_groups_per_batch = 10L
     )

Arguments:

data_candidate_recommendations: Candidate recommendations from
          [diagnose_trait_review_candidates()].

data_approved_decisions: Current canonical decisions from
          [load_trait_review_decisions()].

data_proposal_diagnostics: Recovered selector diagnostics from
          [diagnose_trait_review_candidates()].

data_dataset_evidence: Dataset summaries from
          [build_trait_review_evidence_packets()].

data_record_evidence: Record evidence from
          [build_trait_review_evidence_packets()].

data_agent_adjudications: Completed adjudications. May be a zero-row
          data frame.

evidence_reference: Non-empty path to the human-readable triage report.

min_source_pattern_candidates: Minimum candidates sharing a
          source/factor pattern before escalation.

source_factor_relative_tolerance: Maximum relative error from factors
          10, 100, or 1000.

agent_groups_per_batch: Maximum exception groups assigned to one
          initial agent batch.

Value:

     A named list containing candidate triage, completed-investigation
     no-action proposals, pending programmatic cases, exception
     memberships and groups, a cost-gated agent queue, and summary.
