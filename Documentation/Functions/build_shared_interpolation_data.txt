Build a Shared Interpolation Descriptor

Description:

     Shares interpolation data with [mori::share()] and returns a
     stable descriptor instead of persisting a process-local memory
     handle.

Usage:

     build_shared_interpolation_data(data_interpolation = NULL, registry_key = NULL)

Arguments:

data_interpolation: A data frame to share across local worker
          processes.

registry_key: Optional non-empty key used to retain the shared object
          in a process-local registry. Reusing a key replaces the
          previous region.

Details:

     The live memory name is written to the store-scoped directory in
     `BIODYNAMICS_INTERPOLATION_SHARED_REGISTRY`. Workers must treat
     the mapped data as read-only.

Value:

     A list containing `registry_key` and deterministic `source_hash`.

See Also:

     [mori::share()]

Examples:

     data_interpolation <-
       tibble::tibble(dataset_name = "core_a")

     data_shared <-
       build_shared_interpolation_data(
         data_interpolation = data_interpolation
       )
