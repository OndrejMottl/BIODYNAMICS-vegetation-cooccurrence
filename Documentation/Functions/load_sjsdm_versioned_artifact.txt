Load a Versioned sjSDM Artifact

Description:

     Reads the canonical v2 target first and falls back to a documented
     v1 target group that is upgraded by a pure converter.

Usage:

     load_sjsdm_versioned_artifact(
       store_path = NULL,
       v2_target_name = NULL,
       v1_target_names = NULL,
       artifact_type = NULL,
       converter_function = NULL,
       read_target_function = targets::tar_read_raw
     )

Arguments:

store_path: Targets store path.

v2_target_name: Canonical v2 target name.

v1_target_names: Documented v1 target names.

artifact_type: Expected artifact type.

converter_function: Function accepting the named v1 target bundle.

read_target_function: Injectable target reader.

Value:

     Validated native or converted v2 artifact.
