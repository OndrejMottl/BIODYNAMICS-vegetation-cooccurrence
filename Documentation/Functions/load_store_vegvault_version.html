load_store_vegvault_versionR Documentation

Load the VegVault Version a Targets Store Was Built From

Description

Reads the 'config_vegvault_release' target of one targets store and returns the VegVault version it records.

Usage

load_store_vegvault_version(
  store_path,
  data_meta,
  read_target_fn = targets::tar_read_raw
)

Arguments

store_path

A single character string with the path to the targets store.

data_meta

Metadata of the store with at least the columns 'name' and 'error', as returned by [targets::tar_meta()], or 'NULL' when it could not be read.

read_target_fn

Function used to load one target. Defaults to [targets::tar_read_raw()].

Details

Stores built before the release record was added to the pipelines have no 'config_vegvault_release' target, so published tables show 'NA' for them rather than a guessed version. The target is read only when its metadata records no error.

Value

A single character string, the VegVault version of the store, for example '"2.0.0"'. 'NA_character_' when the store has no successful 'config_vegvault_release' target.

See Also

[load_vegvault_database_version()], [has_target_succeeded()]

Examples

## Not run:
store_path <-
  "Data/targets/paleo_temporal_europe/pipeline_paleo_temporal"

load_store_vegvault_version(
  store_path = store_path,
  data_meta = targets::tar_meta(store = store_path)
)

## End(Not run)
