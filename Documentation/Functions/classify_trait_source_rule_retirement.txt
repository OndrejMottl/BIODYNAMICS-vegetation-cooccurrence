Classify Trait Source Rule Retirement

Description:

     Classifies each whole-source scaling rule of one VegVault release
     by whether a later release already corrects the source, so that
     the rule can be retired without scaling the source twice.

Usage:

     classify_trait_source_rule_retirement(
       data_source_scale_rules,
       data_trait_records_before,
       data_trait_records_after,
       data_sources_after,
       min_shared_taxa = 3L,
       exponent_tolerance = 0.25
     )

Arguments:

data_source_scale_rules: Rules of the earlier release with
          `source_scale_rule_id`, `data_source_id`,
          `expected_data_source_desc`, `trait_domain_name`,
          `trait_name`, and `scale_factor`.

data_trait_records_before: Unscaled trait records of the earlier
          release with `data_source_id`, `taxon_name`,
          `trait_domain_name`, `trait_name`, and `trait_value`.

data_trait_records_after: Trait records of the later release with the
          same columns. Their `data_source_id` values use the numbering
          of the later release.

data_sources_after: Data sources of the later release with
          `data_source_id` and `data_source_desc`.

min_shared_taxa: Integer scalar. The fewest taxa a rule's source must
          share between the releases before it is classified (default
          `3L`).

exponent_tolerance: Numeric scalar between 0 and 0.5. How far the scale
          exponent may lie from 1 or 0 for `fixed_at_source` or
          `still_unscaled` (default `0.25`).

Details:

     Data source ids are not stable between releases, so a rule's
     source is found in the later release by its exact description. For
     the rule's source and, separately, for all sources of the same
     domain (and trait name, when the rule names one) that no rule
     names, the function takes the median value per taxon in each
     release and the median over shared taxa of the ratio later /
     earlier (`ratio_source`, `ratio_reference`). Dividing the two
     removes any unit change that the later release applied to the
     whole domain. `scale_exponent` is the logarithm of that quotient
     in the base of the rule's `scale_factor`:

     * `fixed_at_source`: the exponent lies within `exponent_tolerance`
     of 1, so the later release applies the rule's factor itself; *
     `still_unscaled`: the exponent lies within `exponent_tolerance` of
     0, so the source keeps its earlier scale; * `absent_from_release`:
     the source has no records of the rule's domain in the later
     release, or its description is not found; * `unresolved`: fewer
     than `min_shared_taxa` shared taxa, or an exponent near neither 0
     nor 1.

     Only positive per-taxon medians enter the ratios.

Value:

     A tibble with one row per rule: the rule fields,
     `data_source_id_after`, `n_taxa_before`, `n_taxa_after`,
     `n_taxa_shared`, `ratio_source`, `ratio_reference`,
     `scale_exponent`, and `retirement_status`.
