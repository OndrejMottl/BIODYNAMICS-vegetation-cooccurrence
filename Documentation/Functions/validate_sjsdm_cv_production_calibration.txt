Validate Calibration Evidence Before Production Tuning

Description:

     Rechecks current representative preparation and saved calibration
     inputs before a production tier can launch tuning. A published
     label is not proof.

Usage:

     validate_sjsdm_cv_production_calibration(
       profile_id,
       data_representatives = NULL,
       validate_preparation_function = validate_sjsdm_cv_preparation_freshness,
       validate_evidence_function = validate_sjsdm_cv_calibration_evidence,
       read_target_function = targets::tar_read_raw,
       load_evidence_function = qs2::qs_read
     )

Arguments:

profile_id: Main spatial or paleo-temporal configuration profile.

data_representatives: Optional representative inventory. Defaults to
          the published CSV.

validate_preparation_function, validate_evidence_function: Injectable
          preparation freshness and calibration compatibility checks.

read_target_function, load_evidence_function: Injectable cached
          production target and calibration evidence readers.

Value:

     Invisibly, `NULL` when the required evidence is compatible.

Examples:

     ## Not run:

     validate_sjsdm_cv_production_calibration("project_modern_spatial_local")
     ## End(Not run)
