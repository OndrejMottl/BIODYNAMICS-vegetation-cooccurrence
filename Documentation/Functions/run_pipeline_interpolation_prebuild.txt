Run a Pipeline Interpolation Prebuild

Description:

     Prebuilds interpolation branches with the configured preprocessing
     workers without invalidating completed target metadata. The active
     R library paths are supplied to target definitions so parallel
     workers can resolve packages from the project library reliably.

Usage:

     run_pipeline_interpolation_prebuild(pipeline_script, pipeline_store, workers)

Arguments:

pipeline_script: Path to the selected targets pipeline script.

pipeline_store: Path to the selected targets store.

 workers: Positive integer number of preprocessing workers.

Value:

     `NULL`, invisibly. The function is called for targets side
     effects.
