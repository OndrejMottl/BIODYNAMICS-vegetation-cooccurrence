Compute an sjSDM Artifact Content Hash

Description:

     Computes the stable xxHash64 identity of one v2 artifact while
     excluding materialization and migration-trace provenance.

Usage:

     compute_sjsdm_artifact_content_hash(
       schema_version = NULL,
       artifact_type = NULL,
       payload = NULL,
       provenance = NULL
     )

Arguments:

schema_version: Non-empty character scalar schema version.

artifact_type: Registered non-empty character scalar artifact type.

 payload: Non-empty named list containing the artifact payload.

provenance: One-row provenance data frame containing the common
          provenance fields.

Value:

     Character scalar xxHash64 content digest.

Examples:

     compute_sjsdm_artifact_content_hash(
       schema_version = "2.0.0",
       artifact_type = "sjsdm_cv_predictions",
       payload = list(data_predictions = tibble::tibble()),
       provenance = tibble::tibble(
         created_at = as.POSIXct("2026-08-11", tz = "UTC"),
         pipeline_id = "pipeline_paleo_core",
         configuration_profile = "project_cz_paleo",
         source_schema_version = "2.0.0",
         migration_applied = FALSE,
         migration_function = NA_character_
       )
     )
