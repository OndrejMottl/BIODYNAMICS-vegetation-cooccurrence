Revalidate Spatial Unit Preparation Before Fitting

Description:

     Reads prepared-fold evidence per resolution and reattempts only
     registered failed preparation roots through the canonical runner.
     Current input hashes are checked by targets; stale metadata alone
     never authorizes an exclusion.

Usage:

     run_sjsdm_unit_fitting_preflight(
       unit_pipeline,
       target_store,
       scale_ids,
       resolution_ids,
       run_pipeline_function = run_pipeline,
       load_metadata_function = load_targets_store_metadata,
       diagnose_endpoints_function = diagnose_sjsdm_cv_preparation_endpoints,
       read_target_function = targets::tar_read_raw,
       verbose = TRUE
     )

Arguments:

unit_pipeline, target_store: Pipeline script and root store path.

scale_ids, resolution_ids: Unique requested units and pipeline
          resolution suffixes.

run_pipeline_function, load_metadata_function: Injectable canonical
          runner and cached metadata loader.

diagnose_endpoints_function, read_target_function: Injectable endpoint
          checker and target reader.

 verbose: Logical controlling progress messages.

Details:

     No tuning or model target is requested. Successful preparation is
     not rebuilt by this check. A failed shared root excludes all its
     resolutions; a resolution-specific root never excludes another
     resolution.

Value:

     A tibble of unit-resolution fitting statuses, reasons and root
     evidence. Missing evidence and unexplained errors block fitting
     after all units have been checked. Changed formerly infeasible
     inputs require stage 01 again.

Examples:

     ## Not run:

     run_sjsdm_unit_fitting_preflight(
       unit_pipeline = "R/Pipelines/pipeline_modern_spatial_resolution.R",
       target_store = "Data/targets/modern_spatial_regional",
       scale_ids = "eu_r005", resolution_ids = c("genus", "family")
     )
     ## End(Not run)
