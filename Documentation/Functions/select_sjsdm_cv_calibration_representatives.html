select_sjsdm_cv_calibration_representativesR Documentation

Select sjSDM CV Calibration Representatives

Description

Deterministically selects the maximum-complexity spatial unit in each analysis-tier-resolution group across continents and every supplied eligible paleo temporal profile. Historical final-model outliers are retained in provenance but do not trigger independent CV ladders.

Usage

select_sjsdm_cv_calibration_representatives(data_units = NULL)

Arguments

data_units

Unit inventory with analysis, grouping, complexity-count, historical-budget, and temporal indicator columns.

Value

Selected unit rows with 'complexity_score' and semicolon-delimited 'selection_reason'.

Examples

## Not run:
select_sjsdm_cv_calibration_representatives(data_units)

## End(Not run)
