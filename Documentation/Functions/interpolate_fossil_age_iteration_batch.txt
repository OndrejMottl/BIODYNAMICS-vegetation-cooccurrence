Interpolate One Fossil Age-Iteration Batch

Description:

     Expands one fossil community dataset across selected age-model
     iterations and interpolates each taxon-iteration series on a
     shared age grid.

Usage:

     .interpolate_fossil_age_iteration_batch(
       vec_iterations,
       dataset_name,
       data_community,
       data_age_uncertainty,
       list_interpolation_arguments,
       interpolate_grouped_time_series_function
     )

Arguments:

vec_iterations: Integer age-model iterations included in the batch.

dataset_name: Dataset identifier restored after joining the nested
          community records.

data_community: Nested community proportions with `sample_name`,
          `taxon`, and `value`.

data_age_uncertainty: Nested age-model records with `sample_name`,
          `iteration`, and `age_uncertainty`.

list_interpolation_arguments: Additional arguments forwarded to
          [interpolate_grouped_time_series()].

interpolate_grouped_time_series_function: Grouped interpolation
          function supplied explicitly for dependency-safe execution
          inside a dynamic target branch.

Value:

     Interpolated community proportions for every selected age-model
     iteration.
