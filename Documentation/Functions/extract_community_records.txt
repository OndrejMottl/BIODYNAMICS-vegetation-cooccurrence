Extract Community Records

Description:

     Extracts nested community records from an in-memory VegVault
     result.

Usage:

     extract_community_records(data_vegvault = NULL)

Arguments:

data_vegvault: A data frame containing the columns `dataset_name` and
          `data_community`.

Details:

     This function extracts an in-memory component. It does not load
     data from persistent storage.

Value:

     A data frame containing `dataset_name` and the unnested
     community-record columns.

Examples:

     data_vegvault <-
       tibble::tibble(
         dataset_name = "example",
         data_community = base::list(
           tibble::tibble(sample_name = "sample_1", Pinus = 10)
         )
       )

     extract_community_records(data_vegvault = data_vegvault)
