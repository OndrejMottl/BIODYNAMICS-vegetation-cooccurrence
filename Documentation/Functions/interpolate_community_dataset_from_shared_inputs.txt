Interpolate Community Dataset from Shared Inputs

Description:

     Slices shared paleo preprocessing inputs to one dataset and
     interpolates it.

Usage:

     interpolate_community_dataset_from_shared_inputs(
       list_interpolation_index = NULL,
       data_community = NULL,
       data_age_uncertainty = NULL,
       n_cores = 1L,
       ...
     )

Arguments:

list_interpolation_index: A metadata object produced by
          [build_community_interpolation_index()].

data_community: Community data or a descriptor from
          [build_shared_interpolation_data()].

data_age_uncertainty: Age-uncertainty data or a shared descriptor.

 n_cores: Number of cores passed to
          [interpolate_paleo_community_with_age_uncertainty()]. Dynamic
          target branches should use `1L`.

     ...: Additional arguments passed to
          [interpolate_paleo_community_with_age_uncertainty()].

Details:

     Inclusive row ranges keep branch payloads constant in size and
     avoid full-table logical masks inside concurrent workers. During
     the one-time migration from persisted live `mori` handles, a
     prebuild may reuse an existing branch object after separately
     confirming durable inputs are current.

Value:

     A data frame with columns `dataset_name`, `taxon`, `age`, and
     `value`.

See Also:

     [build_community_interpolation_index()],
     [interpolate_paleo_community_with_age_uncertainty()]
