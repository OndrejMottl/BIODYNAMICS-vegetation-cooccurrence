assess_sjsdm_staged_benchmarkR Documentation

Assess the Paired sjSDM Staged Benchmark

Description

Compares paired exhaustive and staged benchmark repetitions against the frozen issue 138 runtime, resource, technical, and scientific gates.

Usage

assess_sjsdm_staged_benchmark(
  data_benchmark_runs = NULL,
  list_policy = get_sjsdm_staged_benchmark_policy()
)

Arguments

data_benchmark_runs

One row per strategy and benchmark repetition containing measured resources, fit counts, predictive metrics, technical hashes, and selection evidence.

list_policy

Named list containing the versioned issue 138 acceptance thresholds. Defaults to [get_sjsdm_staged_benchmark_policy()].

Value

A named list containing paired comparisons, criterion-level gate results, and a one-row benchmark decision.
