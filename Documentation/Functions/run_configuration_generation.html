run_configuration_generationR Documentation

Run Project Configuration Generation

Description

Validates modular configuration sources and materialises tracked artifacts.

Usage

run_configuration_generation(
  path_manifest = here::here("Configuration/manifest.yml"),
  path_source_root = here::here(),
  path_destination_root = path_source_root,
  path_spatial_grid = base::file.path(path_source_root, "Data/Input/spatial_grid.csv"),
  path_reference_changes = NULL
)

Arguments

path_manifest

Path to the configuration ordering manifest.

path_source_root

Repository root used to resolve manifest fragment and reference paths.

path_destination_root

Root under which generated artifact paths are written.

path_spatial_grid

Path to the spatial grid catalogue whose 'continent_id' values must all have an entry in 'spatial_crs_by_continent'. Defaults to 'Data/Input/spatial_grid.csv' below 'path_source_root'; generation aborts when the file is missing.

path_reference_changes

Optional path to the declared reference-changes CSV. When 'NULL' (default), any difference from the semantic reference aborts. When supplied, declared differences are accepted and the updated reference is written below 'path_destination_root' with [save_configuration_profile_reference()]; undeclared differences still abort.

Details

The function validates the complete source set and semantic reference in a temporary directory before writing either destination artifact.

Value

Data frame describing validated profiles and their generated catalog fields.
