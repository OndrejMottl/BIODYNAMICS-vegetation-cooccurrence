classify_sjsdm_unit_pipeline_errorR Documentation

Classify an sjSDM Unit Pipeline Error

Description

Distinguishes registered data-feasibility outcomes from unexpected pipeline failures using target-level error metadata.

Usage

classify_sjsdm_unit_pipeline_error(data_target_errors = NULL)

Arguments

data_target_errors

Data frame containing at least 'name' and 'error' columns for errors recorded during one unit execution.

Details

Expected roots must match both a registered target-name pattern and a stable message pattern. Downstream dependency, missing-object, and empty-pattern errors are allowed only as cascades. Known temporal validation cascades are accepted only when the same time slice has a registered expected root. Any other root remains unexpected.

Value

A list with 'status', 'reason_code', 'observed_count', 'required_count', 'root_target', and 'root_error'.
