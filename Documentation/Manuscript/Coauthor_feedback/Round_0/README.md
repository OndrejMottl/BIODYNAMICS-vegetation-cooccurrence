# Co-author feedback: Round 0 (direction briefing)

Round 0 comes before the three manuscript rounds. Co-authors receive the project status report and a cover email before the validity checks ([#184], [#185], [#186]) are run, so that they can comment on the decision rules while the rules can still change.

| Item | Value |
|---|---|
| Report | `Documentation/Reports/Third_report/Project_status_and_direction.pdf` (and the self-contained `.html`) |
| Source | `Documentation/Reports/Third_report/_Project_status_and_direction.qmd` |
| Cover email | `Private/cover_email.md` (git-ignored, local only) |
| Sent | Week of 2026-11-09 (planned) |
| Feedback deadline | 2026-11-20 |
| Methods meeting | Week of 2026-12-14, with the co-authors who opt in (date to be set) |
| Issue | [#197], part of [#180] |

Round 0 is a report, not a manuscript version, so it uses no line-numbered PDF, git tag or `feedback_template.md`.

## Questions asked in the cover email

The briefing informs co-authors of the direction; it does not ask them to approve it. One paper was decided on 2026-11-06, so the earlier question "one publication or a series" is no longer asked. The cover email asks two questions (revised on 2026-11-10):

1. **Co-authorship.** Whether the co-author would still like to be a co-author.
2. **Methods meetings.** Whether they would join one or more methods meetings on the analysis and its interpretation (the first before Christmas), or would rather comment on the first draft in January.

The report section "Open questions" invites further input on nine questions: ecological (Q1 plots against pollen, Q2 a millennial clock, Q3 functional types, Q4 rate of change and the `{RRatepol}` corroboration in [#191]) and methodological (Q5 the scale of the partition, Q6 extent against the number of partners, Q7 drivers through time, Q8 levels of biological organisation, Q9 the decision rules of the four checks). The other topics of the earlier draft of the email (Asia in the main text or the supplement, venue order, availability, CRediT roles) are no longer asked; they stay open in the decisions table of [`response_table.md`](response_table.md).

All co-authors receive the same email, without per-person questions (decided 2026-11-10); the draft per-person questions in `Private/targeted_asks.md` are not sent. Every `Private/` folder under `Coauthor_feedback/` is git-ignored; use it for anything that names individuals' circumstances or contact details.

## Collecting replies

- Save each reply as `<Surname>_feedback.md`, keeping the question numbers above. Save notes from the methods meeting as `meeting_notes_YYYY-MM-DD.md`.
- Keep e-mail addresses and private correspondence details out of this folder.
- Consolidate all replies into [`response_table.md`](response_table.md).
- File every request for a new analysis as an issue in milestone `1️⃣ Co-author round · Results skeleton` and enter its number in the Action column.
- Record the resulting decisions (co-authorship, methods involvement and the open topics in the decisions table of `response_table.md`) in the umbrella issue [#180]. Then freeze the decision rules in [#184], [#185] and [#186] before any replicate result is inspected.
