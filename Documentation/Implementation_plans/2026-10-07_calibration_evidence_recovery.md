## Scope and safeguards

Resolve the ten pre-existing representative calibration input-hash mismatches, refresh the thirteen changed modern-local unit-resolution fold designs, and verify the required representative evidence against current cached inputs. Preserve the existing fold-ladder changes and all unrelated worktree changes. Do not restart stage 03 production fitting, reset stores, force target metadata current, or silently certify unverifiable legacy evidence.

## Execution

1. Verify that production and calibration writers are stopped; snapshot relevant metadata and calibration results.
2. Reproduce the operational-runtime contribution to the current calibration hash. Compare legacy benchmark partition counts with current folds and search for original input snapshots before classifying each mismatch.
3. Refresh only the affected modern-local prepared-fold targets through their normal production pipeline definitions, with the original UTF-8 locale and no fresh-store reset. Verify selected grouped counts, complete preparation, and unchanged heavy upstream object hashes after each unit. Record errors and do not start model fitting.
4. Repair calibration content hashing so operational preparation durations cannot invalidate scientific evidence. Preserve all analytical inputs in the hash, including assignments, response/predictor matrices, candidate settings, fit controls, and confirmation policy. Retain actual durations in provenance. Save content-matched per-fold input fingerprints and candidate/formula/fitting fingerprints for future recovery, avoiding duplicate multi-gigabyte fold payloads. Existing target stores remain the source of the complete inputs.
5. Reuse legacy evidence only when its existing supported full input hash matches current inputs, or when an original snapshot proves scientific equivalence under the new normalization. Never infer equivalence from matching counts or timestamps. Preserve incompatible result/checkpoint files reversibly before any separately approved recalibration.
6. Reassess the representative inventory after the refresh. If GPU recalibration is required, obtain the requested compute decision before launching it; run only required representatives sequentially and keep production stopped.
7. Validate hashes, legacy compatibility, checkpoint recovery, publication blocking, configuration generation, tests, architecture, and CZ smoke workflows for any code changes. Publish current status, provenance, and exact remaining work without claiming unresolved representatives are compatible.

## Acceptance

Every affected modern-local prepared fold is current or has an explicitly reported blocking error. Heavy preprocessing remains cached unless a genuine upstream change is identified. Every required accepted calibration result is verifiably content-matched to its representative inputs and policy; otherwise publication and production resumption remain blocked. No commit or push is authorized.
